ShipContext Privacy Policy

Effective date: 12 November 2026

This privacy policy describes how the Atlassian Forge app ShipContext (“the app”) handles information when it is installed on an Atlassian Jira Cloud site. The app is operated by Baoquan Yang, Independent. Questions about this policy or the app may be sent to nlewisbyt@gmail.com.

What ShipContext does

ShipContext is an issue-context panel (and a matching issue panel) for software teams. When a user opens the panel on a Jira work item, the app reads information about that work item in order to display a short Ship or Wait brief: what appears to have been decided, who is responsible, visible blockers, and a recommendation with one next step.

Information the app may read

The app requests only the following read-only Atlassian scopes, and only uses them to display the panel on the site where it is installed:

  • read:jira-work — to read Jira work-item (issue) information, including fields such as summary and status, sub-tasks, comments, and remote links.
  • read:jira-user — to read user names and avatars for people shown on the work item, such as the assignee and reporter.

Depending on what is visible on that work item, this may include personal data that already exists in the customer’s Jira site, such as display names, account identifiers needed to show a user avatar, and text that users have written in descriptions or comments.

If the app cannot read a field, it says so in the panel. It does not invent missing data. A built-in “Demo scenario” can show fictional sample data (for example, the canned SHIP-42 walkthrough). That sample data is not personal data about real people.

How information is processed and stored

The app does not store personal data on a separate server operated by Baoquan Yang. The app does not write to Jira work items.

Work-item information is processed in Atlassian’s Forge environment, on the Atlassian site where the app is installed, only as needed to display the ShipContext panel to the user who opened it. The operator does not run a separate database, analytics service, or marketing list for this app.

What the app does not do

  • It does not sell personal data.
  • It does not collect personal data for marketing.
  • It does not use Teamwork Graph or Rovo.
  • It does not require users to create a separate ShipContext account.

Access, site administration, and Atlassian’s role

The app can only read information that the installing site and the signed-in user are already permitted to see in Jira. Site administrators control whether the app is installed and can uninstall it. Atlassian provides the Forge platform and the Jira Cloud product; Atlassian’s own privacy terms also apply to data held in the customer’s Atlassian account and site.
